# Tutti — Fase 2: Palco 3D — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar os quadrados coloridos do centro do app pelos seis mascotes 3D animados aprovados no mockup, reagindo em tempo real ao estado de cada agente (disponível, pensando, trabalhando, esperando você, concluído), com balão de fala, nome, ferramenta e pílula de estado.

**Architecture:** Toda a lógica que decide *o que* o mascote mostra é pura e testada: `derive.ts` transforma o `ChatState` da Fase 1 em pose + balão por agente; `motion.ts` transforma pose + tempo em transformações e expressão. Os componentes React Three Fiber só leem esses valores a cada quadro. Rótulos e balões são HTML (drei `<Html>`), então continuam testáveis pelo Playwright.

**Tech Stack:** three 0.187.0, @react-three/fiber 9.8.2, @react-three/drei 10.7.9, @types/three 0.187.0, @react-three/test-renderer 9.1.1 (testes da cena sem WebGL), vitest 5.

**Spec:** `docs/superpowers/specs/2026-10-30-time-de-agentes-design.md` (§4 elenco/mascotes, §9 interface, §9.1 mascotes). **Referência visual obrigatória:** `docs/mockups/tela-principal.html` — funções `makeEye` (l.152), `makeScreen` (l.166), `starGeometry` (l.188), `makeMascot` (l.205), `tick` (l.296). Portar formas, proporções, cores e animações de lá.

- `prefers-reduced-motion: reduce` → animações com amplitude zero (só troca de expressão).
- 60 fps alvo com 6 mascotes; `dpr={[1, 2]}`; sombras só de uma luz.

### Task 1: Estado de cada mascote a partir do chat

**Files:**
- Create: `src/renderer/stage/derive.ts`
- Test: `tests/renderer/stage/derive.test.ts`

**Interfaces:**
- Consumes: `ChatState`, `RunBlock`, `AgentStatus` de `src/renderer/state/chat.ts` (Fase 1); `AGENTS`.
- Produces:
  ```ts
  export type Pose = 'idle' | 'thinking' | 'working' | 'waiting' | 'done' | 'locked'
  export interface MascotView { pose: Pose; label: string; bubble?: string; bubbleKind?: 'dots' | 'text' | 'alert' }
  export function deriveStage(chat: ChatState, now: number): Record<AgentId, MascotView>
  export function bubbleText(raw: string, max = 60): string
  export const DONE_BUBBLE_MS = 4000
  ```

Regras (cada uma vira teste): agente com `availableInPhase === 3` → `pose 'locked'`, `label 'Fase 3'`, sem balão. Para os demais, olha o **último** `RunBlock` do agente:
- nenhum run, ou último run com status `cancelled`/`error`/`interrupted` e `finishedAt` há mais de `DONE_BUBBLE_MS` → `idle`, `Disponível`, sem balão.
- último run `running` com aprovação pendente (`allowed === undefined`) → `waiting`, `Esperando você`, balão `alert` = `Preciso da sua aprovação: <summary>` (passado por `bubbleText`).
- `running`, sem passos e sem texto → `thinking`, `Pensando`, balão `dots`.
- `running` com passos → `working`, `Trabalhando`, balão `text` com o último passo: `Bash` → `Rodando <summary>`, `Edit`/`Write`/`MultiEdit` → `Editando <summary>`, `Read`/`Glob`/`Grep` → `Lendo <summary>`, `Shell` → `Rodando <summary>`, outro → `<name> <summary>`.
- `done` com `finishedAt` há menos de `DONE_BUBBLE_MS` → `done`, `Concluído`, balão `text` = primeira linha não vazia do `text` do run (ou `Pronto.` se vazio); depois disso → `idle`, `Disponível`, sem balão.
- `error` há menos de `DONE_BUBBLE_MS` → `idle`, `Disponível`, balão `alert` = `Deu erro: <error>`; `cancelled` → balão `text` `Cancelado.`.

- [ ] **Step 1: Testes que falham** — um `it` por regra acima, montando o `ChatState` com `emptyChat()` + `applyEvent` (já existentes). Inclui, explicitamente:
  - `bubbleText('linha 1\nlinha 2')` → `'linha 1'`; texto de 80 caracteres → 59 caracteres + `'…'`; `` '```ts\ncode' `` → `'code'` (ignora linhas que são só cerca de código); espaços repetidos colapsam.
  - **Review Focus 4:** `chatFromHistory` com um run `interrupted` antigo (`finishedAt` = `now - 10_000`) → `idle`, `Disponível`, sem balão.
- [ ] **Step 2:** `npx vitest run tests/renderer/stage/derive` → FAIL (módulo não existe).
- [ ] **Step 3:** Implementar `deriveStage` e `bubbleText` em `derive.ts`.

### Task 2: Movimento e expressões (puro)

**Files:**
- Create: `src/renderer/stage/motion.ts`
- Test: `tests/renderer/stage/motion.test.ts`

**Interfaces:**
- Consumes: `Pose` (Task 1).
- Produces:
  ```ts
  export type Expression = 'normal' | 'squint' | 'happy'
  export interface MotionFrame { y: number; rotZ: number; rotY: number; squash: number; expression: Expression; eyeDY: number; eyeDX: number; blink: boolean; spin: number }
  export function motionFrame(pose: Pose, t: number, phase: number, sincePose: number, opts?: { float?: boolean; defaultExpression?: Expression; reduced?: boolean }): MotionFrame
  export function screenText(pose: Pose, t: number, blink: boolean): string
  export const DONE_JUMP_S = 1.3
  ```
  Valores portados de `tick()` do mockup: idle `y = sin(2t+φ)·0.022` (flutuante 0.07), `rotY = sin(0.6t+φ)·0.14`, piscada quando `(t + 2φ) mod 4.2 < 0.12`; thinking `rotZ = sin(3t+φ)·0.07`, `eyeDY 0.06`, `eyeDX = sin(1.5t+φ)·0.05`; working `k = |sin(9t+φ)|`, `y = 0.07k`, `squash = 1 − 0.04k`, expressão `squint`; done `happy` e pulo `|sin(7s)|·0.24·(1.3 − s)` enquanto `s < DONE_JUMP_S` (s = `sincePose`); waiting (novo): `y = 0`, `rotY = 0` (olha para a câmera), `rotZ = sin(6t)·0.04`, `eyeDY 0.03`; locked: igual idle com amplitude ×0.4 e sem piscar. `spin` = velocidade do acessório: thinking 0.08, working 0.15, demais 0.01.

- [ ] **Step 1: Testes que falham:**
  - working → `expression 'squint'`, `0 ≤ y ≤ 0.07`, `squash ≤ 1`.
  - done com `sincePose = 0.2` → `y > 0` e `happy`; com `sincePose = 2` → `y` na faixa do idle (`|y| ≤ 0.022`) e ainda `happy`.
  - idle pisca em `t` com `(t + 2φ) mod 4.2 = 0.05` e não pisca em `= 1`.
  - waiting → `rotY === 0` e `y === 0`.
  - `defaultExpression: 'squint'` (Forja) → idle mantém `squint`; thinking também; done vira `happy`.
  - `reduced: true` → `y`, `rotZ`, `rotY` iguais a 0 em todas as poses, expressão inalterada.
  - `screenText`: idle alterna `'>_'`/`'> '` a 1.6 Hz; blink → `'- -'`; thinking → `'.  '`, `'.. '`, `'...'` em sequência a 3 Hz; working → alterna a 6 Hz; done → `'^ ^'`; waiting → `'!'`.
- [ ] **Step 2:** FAIL. **Step 3:** implementar. **Step 4:** PASS.
