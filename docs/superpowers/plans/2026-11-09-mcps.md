# MCPs no Tutti — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Instalar MCPs no Tutti (app e terminal) e entregá-los a todos os agentes. Escrita só para agentes Claude e com aprovação a cada uso; Codex e opencode recebem só as ferramentas de leitura.

**Architecture:** O MCP vive no núcleo (`src/main/mcp/`), com os módulos abaixo, e a tela do app e o painel `/mcp` do terminal só chamam o `McpService`.
- `shared/mcp.ts`: tipo do MCP e regra de leitura.
- `McpService`: guarda os MCPs no banco, guarda segredos no `KeyStore`, importa do Claude Code e lista as ferramentas pelo cliente MCP.
- `forAgent.ts`: decide o que cada agente recebe.
- Lançador: tira os segredos da linha de comando.

**Tech Stack:** `@modelcontextprotocol/sdk` 1.32.2 (dependência direta nova, mesma versão que já vem pelo SDK do Claude), Agent SDK do Claude, Codex SDK (`mcp_servers.<nome>.enabled_tools`), opencode 2.x (`mcp` + `permission` no `opencode.json`), zod, Ink, React.

**Spec:** `docs/superpowers/specs/2026-11-09-mcps-design.md`

## Global Constraints
- Segredo de MCP nunca em: banco em texto puro, log, linha de comando (`ps`) ou env de agente CLI. Só no Keychain (`KeyStore`) e num arquivo temporário 0600 que o lançador apaga.
- Escrita de MCP só em agente Claude por CLI e sempre com aprovação, **inclusive no nível Sozinho**.
- Codex, opencode e agentes por API recebem só as ferramentas de leitura. Consulta, triagem e escalação não recebem MCP.
- Leitura: nome começando com `get`, `list`, `search`, `read`, `fetch`, `find`, `query`, `describe`, `view`, `show` ou `extract`, ou `browser_snapshot`/`browser_take_screenshot`, ou `readOnlyHint: true`. `destructiveHint: true` é sempre escrita. Ferramenta fora da lista salva conta como escrita.
- Nunca chamar `agy mcp add` (grava na config global do Antigravity).
- Playwright importado entra desligado e, quando ligado, nunca vai para agente que tem o navegador do Tutti.
- Textos em português do Brasil. Commits com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Suíte com PATH sem duplicatas.

## Review Focus
1. **MCP que não conecta:** comando errado ou `npx` sem rede. Ele é salvo desligado, com o erro na tela, e nenhum pedido trava por causa dele. O teste fica na Task 2.
2. **Ferramenta nova de um MCP atualizado,** que não está na lista salva. Tem que contar como escrita, mesmo com nome de leitura. O teste fica na Task 3.
3. **Segredo na linha de comando:** em nenhuma config gerada (Claude, Codex, opencode) o valor de um segredo aparece. O teste fica na Task 4.
4. **Nível Sozinho com escrita de MCP:** continua pedindo aprovação. O teste fica na Task 5.
5. **opencode ocupado quando a lista muda:** o servidor não reinicia no meio de um pedido. O teste fica na Task 5.

### Task 3: O que cada agente recebe (`forAgent.ts`) e o lançador

**Files:**
- Create `src/main/mcp/forAgent.ts` e `src/main/mcp/launcher.ts`
- Test `tests/main/mcp/forAgent.test.ts` e `tests/main/mcp/launcher.test.ts`

**Interfaces — Produces:**
```ts
export interface AgentMcp { def: McpServerDef; allowed: string[] | 'all'; secrets: Record<string, string> }  // 'all' só Claude com mode write
export function mcpForAgent(agent: AgentDef, defs: McpServerDef[], o: { mode?: 'work' | 'consult'; hasTuttiBrowser: boolean; secretsOf(id: string): Record<string, string> }): AgentMcp[]
export function isAllowedMcpTool(mcps: AgentMcp[], toolName: string): 'read' | 'write' | 'deny'  // toolName = mcp__<nome>__<tool>
// launcher.ts — segredo fora da linha de comando
export function launchCommand(def: McpServerDef, secrets: Record<string, string>, dir: string): { command: string; args: string[]; env: Record<string, string>; cleanup(): void }
export const LAUNCHER_JS: string   // conteúdo do lançador (node): lê o JSON 0600, apaga, executa command/args com o env
```
Regras de `mcpForAgent`:
- Ignora MCP com `enabled:false`.
- Agente fora da lista (`agents` diferente de 'all' e sem o id dele): não recebe.
- `consult`: nada.
- `playwright` com `hasTuttiBrowser`: nada.
- Claude CLI + `write`: `allowed:'all'`. Qualquer outro caso: `readToolNames(def)`.
- Lista de leitura vazia em agente não-Claude: não recebe.

`isAllowedMcpTool`:
- ferramenta na lista de leitura → 'read';
- `allowed:'all'` e fora da lista → 'write';
- resto → 'deny'.

Isso inclui ferramenta nova que não está em `def.tools`: em agente Claude com `write` ela é 'write' e pede aprovação; nos outros é 'deny'.

`launchCommand`:
- Sem segredos: devolve o `command`/`args` originais e `env` vazio.
- Com segredos: grava `{command, args, env}` num arquivo 0600 em `dir` e devolve `command: process.execPath`, `args: [<dir>/tutti-mcp-launch.cjs, <arquivo>]` e `env: { ELECTRON_RUN_AS_NODE: '1' }`.

- [ ] Testes:
  - Codex não recebe `save_thing`, nem em MCP `write`. Claude com `write` recebe 'all'.
  - Consulta e agente fora da lista: nada.
  - Playwright com navegador: nada.
  - `isAllowedMcpTool` com ferramenta nova (fora de `def.tools`) num Claude `write`: 'write'; num Codex: 'deny'. Cobre o item 2 do Review Focus.
  - `launchCommand` com segredo: nenhum valor do segredo aparece em `command`, `args` ou `env`.
  - Rodar `LAUNCHER_JS` com node num arquivo de teste: o filho recebe a variável e o arquivo some.
- [ ] Rodar: FAIL. Implementar. Rodar: PASS. Commit `feat: MCP por agente e lançador sem segredo na linha de comando`.
